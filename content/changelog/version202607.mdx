# JAsk v.2026.07

## 🧠 Modèles, agents & réflexion
 
- **Nouveaux modèles disponibles** : Gemini (via Google AI Studio), Vertex AI (Google Cloud) et Deepseek en accès direct rejoignent la liste des modèles connectables. Le Model Foundry s'enrichit également de nouveaux fournisseurs (Mistral, Deepseek…). Voir la [doc Modèles LLM](https://docs.jask.auria-software.com/docs/catalog/ai_models).
- **Modèle par défaut par skill** : dans les paramètres avancés d'un skill, vous pouvez désormais imposer le modèle utilisé — utile quand un skill donné tourne mieux avec un modèle précis.
- **Skills plateforme** : Vous pouvez forcer que certains skills soient accessibles à tous les agents de la plateforme. Peu importe si le créateur a pensé à le rajouter. Cela permet de systématiser l'usage pour des éléments "standards" comme la génération de slides ou d'excel par exemple.
- **Modèles épinglés** : épinglez vos modèles favoris pour les retrouver directement sur votre page d'accueil.
- **Niveau de réflexion** : un niveau de réflexion par défaut d'un agent peut maintenant être fixé au niveau de l'agent. Vous pouvez choisir de laisser, ou non, vos utilisateurs le modifier eux-mêmes depuis leur profil.
- **Modèle de l'agent** : De manière identique, vous pouvez définir un modèle par défaut sur un agent, et laisser ou non la possibilité aux utilisateurs de l'éditer pour leur usage personnel.
- **Agent par défaut** : configurable à la fois par groupe d'utilisateurs et dans le profil de chaque utilisateur, pour forcer l'utilisation d'un certain agent à des utilisateurs ou un groupe d'utilisateurs.
- **Partage d'agents restreint au tenant Azure** : pour éviter qu'un agent ne soit partagé en dehors de votre organisation.
- **Skills et workflows personnalisables** : ajoutez un avatar sur vos skills et workflows pour les repérer plus facilement dans la liste.
- Et une série de correctifs : lancement d'un agent depuis son panneau latéral, lien direct vers un agent corrigé, duplication d'un agents...
## 📚 Sources, RAG & indexation
 
- Correction d'un bug qui cassait le RAG sur les agents nouvellement créés.
- Les sources ne s'affichent plus en double dans le panneau de sources.
- Indexation Excel corrigée.
- Modifier la configuration d'une source invalide n'invalide plus tout l'affichage de l'indexation.
- Le message "deep search" qui s'affichait à l'appel d'une source a été retiré.

## 💬 Conversations & panneau de réflexion
