## Les workflows custom

Créés par vous ou votre organisation, ces workflows permettent de réaliser une série de tâches spécifiques de manière automatisée selon la configuration qui a été définie. Vous pouvez sélectionner les workflows via la commande @ ou en cherchant dans le catalogue. Et l'exécuter directement depuis la page d'accueil.

### Les workflows natifs (Microsoft)

Ils sont présents par défaut sur votre environnement et permettent d'intéragir avec des ressources Microsoft (emails, transcripts, sharepoints, MS Graph...).

[Voir plus](/docs/catalog/agents/applications)

## Interroger vos bases de données

Recherchez des informations dans les bases de connaissance de votre organisation. L'IA va générer une réponse en fonction de votre requête en se basant sur les bases de données sélectionées. Vous pouvez **sélectionner une ou plusieurs sources de données** que vous souhaitez interroger avec votre requête en utilisant la commande / puis en tapant le nom de la source

## Enchaîner les interactions

Depuis l'accueil, vous pouvez enchaîner plusieurs services présentés précédemment. Cela vous permet de poursuivre, d'approfondir ou de challenger les résultats fournis par l'IA Par exemple, vous pouvez :

- **Exécuter** un workflows
- **Rebondir sur le résultat du workflow** avec un agent pour approfondir

## Croiser les services

|  |
| --- |
| L'agent répond à la requête de l'utilisateur en prenant en compte les fichiers importés (si c'est le cas) |
| Le skill répond a une demande de l'utilisateur de manière unitaire. Il peut aussi être attaché à un agent, qui appelera le skill et ses instructions si l'agent identifie que le skill peut être utile pour répondre à la requête de l'utilisateur. |
| Le groupe d'agents répond à la requête de l'utilisateur en fonction du mode de fonctionnement défini dans le groupe. |
| Le workflow se lance en prenant en contexte la requête/fichier saisis par l'utilisateur (si c'est le cas). Si l'application ne permet pas de prendre en contexte un fichier, le fichier importé sera ignoré. |
| L'IA répond à la requête de l'utilsateur en interrogeant la base de données séléctionnée. Si un fichier est importé, l'IA traitera la base de données sélectionnée et le fichier comme deux sources distinctes pour générer sa réponse. |
| Les agents sélectionnés répondent parallèlement à la requête de l'utilisateur. |
| Les workflows sélectionnés sont déclenchés en parallèle. |
| Les bases de données sont utilisées par l'IA pour répondre à la requête de l'utilisateur. |
|  |
