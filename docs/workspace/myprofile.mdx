La page **Mon profil** regroupe les paramètres propres à votre compte Jask.

Vous pouvez y consulter vos permissions et gérer vos informations, vos préférences, votre agent par défaut, vos connexions et vos secrets. Vos modifications n’affectent pas le profil des autres membres de l’organisation.

## Accéder à votre profil

<Steps>
  <Step title="Ouvrir les réglages">
    Dans la barre latérale, ouvrez **Réglages**.
  </Step>
  <Step title="Ouvrir votre profil">
    Dans le menu **Mon espace de travail**, sélectionnez **Mon profil**.

    La page affiche les informations et les paramètres associés à votre compte.
  </Step>
</Steps>

<Frame caption="La page Mon profil dans les réglages de l’espace de travail.">
  ![Page Mon profil affichant le résumé du compte, les informations personnelles et les préférences.](/images/myprofile.png)
</Frame>

## Consulter le résumé de votre compte

Le bandeau situé en haut de la page indique le nombre de ressources auxquelles vous avez accès :

- **Agents** ;
- **Skills** ;
- **Modèles IA** ;
- **Sources de données**.

Ces compteurs représentent vos accès personnels. Ils peuvent donc différer de ceux des autres membres de l’organisation.

## Modifier vos informations

La section **Informations du compte** contient les champs suivants :

| Champ | Description | Modification |
| --- | --- | --- |
| **Identifiant** | Identifiant technique unique de votre compte | Non modifiable |
| **Email** | Adresse professionnelle utilisée pour l’authentification | Non documentée depuis cette page |
| **Nom** | Votre nom | Modifiable |
| **Prénoms** | Vos prénoms | Modifiables |
| **Titre** | Votre intitulé de poste | Modifiable |

<Steps>
  <Step title="Modifier une information">
    Dans **Informations du compte**, modifiez **Nom**, **Prénoms** ou **Titre**.
  </Step>
  <Step title="Vérifier la modification">
    La modification est enregistrée automatiquement. Aucun message de confirmation ne s’affiche.
  </Step>
</Steps>

## Personnaliser l’affichage

La section **Préférences** permet de personnaliser votre interface. Ces réglages ne concernent que votre compte.

| Préférence | Effet |
| --- | --- |
| **Langue** | Change la langue de l’interface. Les langues proposées sont le français, l’anglais, le japonais et le chinois. |
| **Mode sombre** | Active ou désactive le thème sombre. |
| **Thème** | Change la couleur d’accent de l’interface parmi les quatre teintes proposées. |

<Steps>
  <Step title="Choisir une préférence">
    Dans la section **Préférences**, modifiez la langue, le mode d’affichage ou le thème.
  </Step>
  <Step title="Vérifier le résultat">
    La préférence est enregistrée automatiquement. Aucun message de confirmation ne s’affiche.

    Vérifiez que la langue, le mode d’affichage ou la couleur d’accent de l’interface a changé.
  </Step>
</Steps>

## Choisir votre agent par défaut

L’**Agent par défaut** est sélectionné automatiquement lorsque vous démarrez une conversation sans choisir d’agent.

L’agent utilisé peut provenir :

- de la configuration de votre organisation ;
- de la configuration d’un de vos groupes ;
- de votre sélection personnelle.

Une sélection manuelle remplace l’agent attribué par l’organisation ou par un groupe.

{/* DÉDUIT: le contrôle prend probablement la forme d’une liste de sélection, mais son type exact n’est pas fourni. */}

<Steps>
  <Step title="Sélectionner un agent">
    Dans **Agent par défaut**, choisissez l’agent à utiliser pour vos nouvelles conversations.
  </Step>
  <Step title="Vérifier votre choix">
    Le choix est enregistré automatiquement. Aucun message de confirmation ne s’affiche.

    Démarrez une nouvelle conversation sans sélectionner d’agent. Vérifiez que l’agent choisi est utilisé.
  </Step>
</Steps>

Pour revenir à la configuration attribuée à votre compte, sélectionnez **Réinitialiser (groupe ou Jask par défaut)**.

## Personnaliser le modèle et le niveau de réflexion

Le créateur d’un agent peut autoriser les utilisateurs à personnaliser :

- le **modèle IA** utilisé ;
- le **niveau de réflexion** appliqué à l’agent.

Ces réglages sont enregistrés individuellement pour chaque agent. Selon la configuration de l’agent, vous pouvez personnaliser un seul paramètre ou les deux.

<Steps>
  <Step title="Sélectionner l’agent">
    Dans la liste des agents, repérez celui que vous souhaitez personnaliser.
  </Step>
  <Step title="Choisir le modèle IA">
    Si ce paramètre est disponible, choisissez l’un des modèles IA proposés pour cet agent.
  </Step>
  <Step title="Choisir le niveau de réflexion">
    Si ce paramètre est disponible, sélectionnez le niveau de réflexion à appliquer.
  </Step>
  <Step title="Vérifier la personnalisation">
    Les paramètres sont enregistrés automatiquement pour cet agent. Aucun message de confirmation ne s’affiche.

    Vérifiez que le modèle IA et le niveau de réflexion sélectionnés restent affichés pour l’agent.
  </Step>
</Steps>

<Tip>
  **Modèle par défaut** indique que l’agent utilise le modèle prévu par sa configuration. **Réflexion non personnalisée** indique qu’aucun niveau propre à votre compte ne remplace la configuration de l'agent.
</Tip>

## Gérer vos connexions

La section **Connexions** liste les services tiers connectés à votre compte et utilisés dans vos skills et conversations, par exemple Salesforce ou Odoo.

### Déconnecter un service

<Steps>
  <Step title="Repérer la connexion">
    Dans **Connexions**, trouvez le service que vous souhaitez déconnecter.
  </Step>
  <Step title="Déconnecter le service">
    Cliquez sur **Déconnecter**.
  </Step>
  <Step title="Confirmer la déconnexion">
    Confirmer la déconnexion du service
  </Step>
</Steps>

<Warning>
  La déconnexion peut interrompre les agents ou les skills qui utilisent ce service dans vos conversations.
</Warning>

## Gérer vos secrets

Un secret est un identifiant ou un jeton utilisé par un agent pour accéder à un service.

La section **Secrets** regroupe les secrets que vous avez créés ou utilisés dans une conversation avec un agent. Pour chaque secret, elle affiche :

- son nom ;
- le service associé ;
- son statut, **Valide** ou **Expiré** ;
- une action pour le modifier ;
- une action pour le supprimer.

### Ajouter un secret

<Steps>
  <Step title="Commencer l’ajout">
    Dans la section **Secrets**, cliquez sur **\+ Cliquez pour ajouter**.
  </Step>
  <Step title="Renseigner le secret">
    Coller le secret de l'application à connecter à Jask
  </Step>
  <Step title="Valider le secret">
  </Step>
  <Step title="Vérifier le résultat">
    Vérifiez que le secret apparaît dans la liste avec le statut **Valide**.
  </Step>
</Steps>

### Modifier un secret

<Steps>
  <Step title="Ouvrir le secret">
    Dans la liste, cliquez sur l’icône en forme de crayon correspondant au secret.
  </Step>
  <Step title="Mettre à jour les informations">
  </Step>
  <Step title="Vérifier le statut">
    Vérifiez que le secret affiche le statut **Valide**.
  </Step>
</Steps>

### Supprimer un secret

<Steps>
  <Step title="Sélectionner le secret">
    Dans la liste, cliquez sur l’icône en forme de corbeille correspondant au secret.
  </Step>
  <Step title="Confirmer la suppression">
    Une confirmation s’affiche avant la suppression.
  </Step>
  <Step title="Vérifier la suppression">
    Vérifiez que le secret n’apparaît plus dans la liste.
  </Step>
</Steps>

<Warning>
  La suppression d’un secret peut empêcher les agents qui en dépendent d’accéder au service associé.
</Warning>

## Résoudre les problèmes courants

<AccordionGroup>
  <Accordion title="Un secret affiche le statut « Expiré »">
    **Cause :** le secret n’est plus accepté par le service associé.

    **Correctif :** cliquez sur l’icône en forme de crayon et renouvelez ses informations.
  </Accordion>

  <Accordion title="Mon agent par défaut n’est pas utilisé">
    Vérifiez qu’une sélection personnelle apparaît dans la section **Agent par défaut**.

    Si vous avez sélectionné **Réinitialiser (groupe ou JAsk par défaut)**, l’agent attribué par votre groupe ou par JAsk est utilisé.
  </Accordion>

  <Accordion title="Un agent ne peut plus accéder à un service">
    Vérifiez dans **Connexions** que le service est toujours connecté.

    Vérifiez ensuite dans **Secrets** que le secret associé affiche le statut **Valide**.
  </Accordion>
</AccordionGroup>
