Les rôles dans Jask donnent accès à des fonctionnalités ou des vues particulières. Ils s'appliquent aux comptes utilisateurs connus dans Jask.

Un utilisateur se verra attribuer l'ensemble des rôles définis sur son profil et sur les groupes auxquels il appartient.

<Info>
  Seul un utilisateur avec le droit `Utilisateurs` peut les gérer
</Info>


<Info>
  Tous les rôles sous Espace de travail sont groupés et assignés ensemble. Dès qu'un groupe ou utilisateur se voit attribué un rôle supérieur, ceux rôles sont automatiquement fournis.
</Info>
