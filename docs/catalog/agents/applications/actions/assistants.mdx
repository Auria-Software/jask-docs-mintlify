title: "Appeler un Agent"
sidebarTitle: "Agents"
---

A la différence d'un simple prompt, l'agent est relié à des sources de données, à un prompt système associé et a déjà un modèle d'IA sélectionné. Vous pouvez appeler un agent dans une application pour réaliser une tâche spécifique.

<Info>
Tout ce que vous reliez à gauche de l'action sera passé dans le prompt envoyé à l'agent. Ce qui sort à droite de l'action sera uniquement la réponse de l'agent.
</Info>

![application_assistant](/images/applications/assistant.png)

Écrivez votre instruction (prompt) dans la zone de texte pour guider l'agent à réaliser la tâche.
