Trois actions sont disponibles pour générer des documents :

- Traduire un document à partir d'un document
- Générer un document de zéro à partir d'un texte

![application_document_production](/images/applications/generate.png)

## Traduire un document

L'outil Traduction de JASK vous permet de traduire instantanément vos fichiers (Word, PowerPoint ou IDML) vers la langue de votre choix. 
Pour garantir un résultat optimal et fidèle de vos documents traduits, vous pouvez intégrer des **consignes spécifiques** afin d'ajuster le ton et le style de la traduction.
Vous pouvez y accéder directement apartir du Home en cliquant sur le bouton `+` puis en cherchant `Traduction` comme application, charger le fichier à traduire et enfin les instructions que vous souhaitez.
ou bien via application

### Guide d'utilisation

Cette action vous permet de traduire un document tout en gardant le format du document original. Il accepte en entrée un document (soit depuis le [contexte](/docs/catalog/agents/applications/actions/context), soit depuis le [moteur de recherche](/docs/catalog/agents/applications/actions/data_sources#moteur-de-recherche) etc...).

<Warning>
  La traduction est effectuée uniquement pour les documents Word et PowerPoint.
</Warning>

![application_document_production](/images/applications/translate.png)

Pour utiliser cette action, cliquez sur le bouton `+` puis sur `Production de documents` et enfin sur `Traduire un document`.
Une fois l'action dans le workflow, vous pouvez sélectionner la langue de traduction (Anglais, Espagnol, etc...), donner un nom à votre document traduit et choisir un dossier de sauvegarde ainsi que la source de données dans laquelle vous souhaitez stocker votre document traduit.

### Guide d'utilisation

Cette action vous permet de générer un document à partir d'un texte et de le stocker dans votre source de données choisie.

<Info>
  Le document généré est basique pour l'instant mais il sera bientôt possible de
  générer un document avec un format plus avancé.
</Info>

![application_document_production](/images/applications/generateppt.png)

Vous avez le choix du format du document généré :

- Word
- PowerPoint
- Markdown
- HTML
- PDF
- Excel

Vous pouvez également choisir le nom du nouveau document, le chemin de sauvegarde ainsi que la source de donnée dans laquelle vous souhaitez stocker votre document.
