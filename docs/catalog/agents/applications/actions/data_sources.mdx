Vous pouvez utiliser les sources de données dans un workflow pour récupérer des informations.

![application_data_sources](/images/applications/my_sources.png)

Trois types d'actions sont possibles dans les sources de données :

- Importer un fichier
- Moteur de recherche
- Analyse d'une source

### Guide d'utilisation

Vous pouvez importer un fichier statique dans l'application pour utiliser le contenu dans un [prompt](/docs/catalog/agents/applications/actions/prompts_store) ou un [agent](/docs/catalog/agents/applications/actions/assistants) par exemple.

![application_data_sources](/images/applications/import.png)

Cliquez sur le bouton `+` puis `Mes sources de données` et enfin `Importer un fichier` pour importer un fichier. Une fois l'action créée dans le workflow, vous pouvez y déposer le fichier en son centre.

## Moteur de recherche

### Paramètres

<table>
  <tbody>
    <tr>
      <td>Section</td>
      <td>Mes sources de données</td>
    </tr>
    <tr>
      <td>Titre</td>
      <td>Moteur de recherche</td>
    </tr>
    <tr>
      <td>Définition</td>
      <td>
        Cette brique permet de récupérer une liste de documents depuis vos
        sources de données selon une recherche
      </td>
    </tr>
    <tr>
      <td>Entrée</td>
      <td>Rien ou Texte</td>
    </tr>
    <tr>
      <td>Sortie</td>
      <td>Liste de fichiers</td>
    </tr>
    <tr>
      <td>Paramètres avancés</td>
      <td>
        - Sélection de la source de données depuis laquelle les documents
        proviendront
        <div />
        - Type de recherche : Texte (Recherche textuelle) ou Liste (Liste de
        fichier par rapport à une logique de tri)
        <div />- Si Texte : - Texte : texte saisi dans la brique OU texte en
        entrée de la brique - Nombre de documents à retourner - Pertinence
        minimale à respecter. Similarité entre l’entrée et les docs
        <Warning>
          Si un élément est branché en entrée de cette brique, en mode “Texte”,
          le champ “Texte” de recherche est masqué dynamiquement
        </Warning>
        - Si Liste : - Nombre de documents à retourner - Ordre de tri des
        documents (par date de modification dans la source de données).
        <Warning>
          En type de recherche liste, l’entrée (si elle existe) n’est pas prise
          en compte.
        </Warning>
      </td>
    </tr>
    <tr>
      <td>Exemples d’utilisation</td>
      <td>
        - Je veux la liste des 10 derniers documents créés dans un répertoire
        Sharepoint, et extraire des informations consolidées de ces fichiers
        sous un format tableau.
        <div />- Je veux une liste de tous les documents de mon répertoire
        Sharepoint selon la recherche “CV”, pour trouver le profil le plus
        intéressant par rapport à un besoin décrit par l’utilisateur
      </td>
    </tr>
  </tbody>
</table>

### Guide d'utilisation

Vous pouvez utiliser le moteur de recherche pour trouver un ou des documents dans vos sources de données puis les utiliser dans un [prompt](/docs/catalog/agents/applications/actions/prompts_store) ou un [assistant](/docs/catalog/agents/applications/actions/assistants) par exemple.

<Info>
  La recherche se fait avec l'IA sur l'entièreté du document (metadata +
  contenu)
</Info>

![application_data_sources](/images/applications/search.png)

Cliquez sur le bouton `+ Ajouter` puis `Mes sources de données` et enfin `Moteur de recherche` pour créer l'action. Une fois l'action créée dans le workflow, vous devez choisir une source de données puis le type de recherche à effectuer sur cette source de donnée.

<Info>
  Si vous passez des éléments en entrée de l'action, le texte sera utilisé comme
  mots-clés de recherche (si le type Texte est sélectionné).
</Info>
