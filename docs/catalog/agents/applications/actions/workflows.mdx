Les workflows peuvent eux memes être utilisés comme actions dans d'autres workflows. C'est un excellent moyen d'utiliser un workflow pour une taches spécifique de façon répétitive sur une multitude de documents en entrée.

## Créer un workflow

Pour créer un nouveau workflow rendez-vous dans la page Agents IA > Workflows du catalogue de Jask et cliquez sur le bouton `+ Actions` puis sur `Créer un workflow`.
Suivez la documentation [ici](/docs/catalog/agents/applications/create) pour créer un workflow.

## Utiliser un workflow dans un workflow

Pour utiliser un workflow dans un workflow, cliquez sur le bouton `+` puis sur `Workflows` et enfin sur le workflow à utiliser.
