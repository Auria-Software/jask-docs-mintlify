Les paramètres avancés définissent l’interface et la personnalisation de JAsk pour l’ensemble des utilisateurs de l’organisation.

Contrairement aux réglages de la page **Mon profil**, qui restent individuels, les modifications effectuées sur cette page s’appliquent à l’ensemble de la plateforme.

<Warning>
  Cette page est réservée aux administrateurs. Les modifications prennent effet immédiatement et peuvent affecter l’expérience de tous les utilisateurs.
</Warning>

## Accéder aux paramètres avancés

Vous devez être administrateur pour accéder à cette page et configurer l’interface ainsi que la personnalisation de la plateforme.

Dans la barre latérale, ouvrez **Réglages → Déploiement → Paramètres avancés**.

{/* DÉDUIT: la réponse « OUI » à la question « automatiquement ou via un bouton ? » est interprétée comme un enregistrement automatique. À confirmer explicitement. */}

Les modifications sont enregistrées automatiquement et prennent effet immédiatement.

<Check>
  Une fois un paramètre modifié, vérifiez son effet dans l’interface avec un compte utilisateur concerné.
</Check>

## Configurer l’expérience des chats

La section **Chats** contrôle l’affichage des documents, des résultats de recherche et de la consommation pendant une conversation.

| Paramètre | Effet |
| --- | --- |
| **Ouverture automatique des documents** | Ouvre les documents générés par les agents dans le panneau de droite, sans action supplémentaire de l’utilisateur. |
| **Montrer automatiquement les résultats de recherche** | Ouvre automatiquement le panneau de réflexion à droite pour afficher les résultats de la recherche effectuée par l’agent. |
| **Afficher la consommation** | Affiche dans le panneau de réflexion un résumé de la consommation de tokens associée à la réflexion. |

## Configurer les agents IA

La section **Agents IA** définit les limites de réflexion et les modèles utilisés par défaut sur la plateforme.

| Paramètre | Effet |
| --- | --- |
| **Durée maximale de réflexion des agents** | Définit, en secondes, la durée au-delà de laquelle un agent interrompt sa réflexion. |
| **Modèle IA par défaut** | Définit le modèle utilisé par défaut sur la plateforme. |
| **Modèle IA Vision par défaut** | Définit le modèle utilisé par défaut pour les analyses d’images et les questions portant sur des présentations PowerPoint. |
| **Prompt Système admin** | Ajoute un prompt système défini par l’administrateur à tous les agents de la plateforme lorsque l’option est activée. |

Par exemple, une durée maximale de `3600` secondes interrompt une réflexion qui dépasse une heure.

<Tip>
  Utilisez la durée maximale de réflexion pour empêcher l’exécution indéfinie d’un agent sur une requête complexe, ce qui engendre des coûts indésirables.
</Tip>

## Configurer les skills IA

La section **Skills IA** regroupe les skills transverses de la plateforme.

Ces skills peuvent être mis à disposition globalement, sans être rattachés manuellement à chaque agent. Ils peuvent inclure `just-xlsx` pour les fichiers tableur ou `just-pptx` pour les présentations.

Pour chaque skill, vous pouvez configurer les options suivantes :

| Option | Effet |
| --- | --- |
| **Attacher à tous les agents** | Rend le skill disponible dans tous les agents de la plateforme, indépendamment de son rattachement manuel à un agent. |
| **Modèle** | Définit le modèle utilisé par le skill. Vous pouvez sélectionner un modèle spécifique, comme `gpt-5.5`, ou utiliser le modèle par défaut de la plateforme. |

<Warning>
  Certains skills nécessitent des modèles avancés pour fonctionner correctement. Vérifiez les prérequis du skill avant de modifier le modèle qui lui est associé.
</Warning>

## Configurer la sécurité et la gouvernance

La section **Sécurité et Gouvernance** contrôle le partage, la mémoire des agents, la visibilité des utilisateurs et l’affichage de la charte IA.

| Paramètre | Effet |
| --- | --- |
| **Autoriser le partage de conversations** | Permet aux utilisateurs de partager leurs conversations JAsk avec d’autres utilisateurs. |
| **Activer la mémoire des agents** | Permet aux agents d’enregistrer des informations sur les utilisateurs entre leurs conversations afin de personnaliser leurs réponses. |
| **Afficher uniquement les utilisateurs d’un même tenant** | Limite la visibilité des utilisateurs à ceux du même tenant Azure. |
| **Masquer automatiquement les données personnelles** | Masque automatiquement certaines données personnelles dans les échanges, comme les adresses e-mail, les numéros de téléphone ou les numéros de carte bancaire. |
| **Charte IA** | Affiche une charte d’utilisation de l’IA que chaque utilisateur doit lire et accepter avant d’utiliser la plateforme. |
| **Autoriser le partage via JAsk** | Contrôle l’affichage de cette option dans le formulaire de création d’un agent. Ce paramètre est désactivé par défaut. |

Lorsque vous activez **Charte IA**, rédigez le contenu de la charte dans le champ texte qui apparaît sous l’option.

## Activer ou masquer des fonctionnalités

La section **Fonctionnalités** permet d’adapter les fonctions et les menus visibles dans JAsk aux usages de votre organisation.

| Paramètre | Effet dans l’interface |
| --- | --- |
| **Expériences** | Affiche les fonctions de création de scénarios ou de parcours métier. |
| **Projets collaboratifs** | Affiche l’onglet **Collab**, qui permet de créer des projets entre plusieurs utilisateurs. |
| **Automatisation des tâches** | Affiche l’écran de gestion des automatisations. Les utilisateurs peuvent y créer leurs automatisations d’agents et de workflows. |
| **Terminologie interne** | Active l’utilisation du glossaire de vocabulaire propre à l’organisation. |
| **Agents Workflow** | Affiche les fonctions de création et de gestion des workflows agentiques dans le studio. |
| **Masquer le menu réglage pour les simples utilisateurs uniquement** | Retire le menu **Réglages** de l’interface des utilisateurs concernés, notamment l’accès aux catalogues et aux documents. |
| **Masquer également l’accès au profil utilisateur** | Retire aussi la page **Mon profil** du menu latéral. |
| **Masquer l’effort de raisonnement pour les utilisateurs** | Retire le sélecteur d’effort de raisonnement de la barre de saisie des conversations. |
| **Applications natives** | Retire les applications permettant d’accéder aux données Microsoft 365. Cette fonctionnalité est obsolète. |

<Info>
  La désactivation d’une fonctionnalité la retire de l’interface pour tous les utilisateurs. Elle ne supprime pas les données associées. Si vous la réactivez, les contenus existants redeviennent accessibles dans l’interface.
</Info>

## Configurer la télémétrie

La section **Télémétrie** définit les informations remontées pour suivre l’état de la plateforme et diagnostiquer les erreurs.

| Paramètre | Effet |
| --- | --- |
| **Heart Beat** | Envoie un signal de disponibilité de la plateforme toutes les cinq minutes. |
| **Données d’usage** | Envoie des statistiques anonymisées d’usage afin d’analyser la santé de la plateforme. |
| **Contenu des chats en erreur** | Inclut le contenu des chats en erreur dans les demandes de support à des fins de diagnostic. |

## Identifier la version de l’instance

La section **À propos de JAsk** est en lecture seule. Elle affiche les informations techniques de votre instance.

| Information | Description |
| --- | --- |
| **Identifiant tenant** | Identifiant unique de l’organisation. |
| **Audience API** | URI de ressource de l’application. |
| **Image API** | Nom de l’image de conteneur déployée. |
| **Tag de l’image** | Tag de l’image de conteneur déployée. |
| **Version de l’API** | Version actuellement déployée ou référence de build. |
| **Commit de l’image** | Référence du commit source. |
| **Agent Support** | Interlocuteur indiqué pour l’assistance de la plateforme. |
| **Email Agent support** | Adresse e-mail de cet interlocuteur. |
| **Dernier redémarrage** | Date du dernier redémarrage du serveur. |

Ces informations permettent d’identifier votre instance lors d’un incident ou d’une demande d’assistance.

## Vérifier une modification

Les modifications prennent effet immédiatement.

Après avoir modifié un paramètre, utilisez un compte utilisateur concerné pour vérifier le résultat dans l’interface.

Selon le paramètre modifié, contrôlez :

- l’affichage ou la disparition du menu concerné ;
- l’ouverture automatique des documents ou des résultats de recherche ;
- la disponibilité d’un skill dans un agent ;
- le modèle sélectionné par défaut ;
- l’affichage de la charte IA ;
- l’accès aux fonctionnalités activées.

Si le résultat ne correspond pas à vos attentes, restaurez la valeur précédente depuis **Réglages → Déploiement → Paramètres avancés**.
