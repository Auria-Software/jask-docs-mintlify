## Se repérer dans le menu

Le menu principal donne accès à trois zones : **Chats**, **Collaboration** et **Réglages**.

<Warning>
  Votre plateforme Jask est gérée par vos administrateurs. Certaines des fonctionnalités décrites dans cette documentation peut ne pas s'appliquer à votre organisation si les administrateurs ont décidé de cacher totalement certaines fonctionnalités, ou de les rendre disponibles uniquement à certains utilisateurs.
</Warning>

## Personnaliser votre interface

Ouvrez le menu associé à votre nom pour accéder aux préférences de l’interface. Dans Réglages, la section Mon Profil vous permettra de personnaliser encore plus votre expérience.

Vous pouvez :

- choisir la langue de l’interface (entre français, anglais, chinois et japonais) ;
- utiliser le mode clair ou sombre ;
- sélectionner l’un des thèmes proposés ;
- vérifier quel utilisateur est connecté ;
- vous déconnecter de Jask.
